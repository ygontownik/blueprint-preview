## What the blueprint covers

- **Two-axis architecture:** 6 operating layers × 7 capability planes = 42 explicit contract cells
- **Hierarchical synthesis:** same canonical state synthesized to 4 resolutions (staff / PM / DR / group head) via Haiku → Sonnet → Opus per role tier
- **Signal quality gate:** 4-dimension triage at capture before items touch the canonical state
- **Cross-program learning engine:** per-program durable knowledge graduates to org-level best practices; peer learnings auto-surfaced via structural similarity map
- **External intelligence ingestion:** 4-tier federal feed taxonomy (regulatory, agency, market, congressional) with readthrough engine matching to programs and stakeholder intelligence layer tracking public statements
- **Tiered visibility:** three-layer enforcement (Claude Enterprise access, compile-time role-tier state files, per-tier CLAUDE.md constraints)
- **~70% leverage:** every recommendation cites the reference pattern inherited from three production repos (Private-Yoni-Dashboard, Invite-Chief-of-Staff, Private-Yoni-Config)

## Why it exists

The blueprint is the execution document for translating an AI operating system proven at small scale (2–3 person investment platform) into a 400-FTE federal policy office. It is federal-native: respects FedRAMP, ATO, FOIA, classification, union dynamics. Every section names systems, owners, reference patterns, ATO paths, costs, and 90-day success metrics.

All data is illustrative. No real agency, no real programs.
